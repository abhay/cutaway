Questions

How accurate are the cutaways?

Each demo explains where it simplifies shapes, timing, or flow. Generated drawings can contain mistakes, so ask for sources and check a reference diagram when a detail matters.

Do I need ChatGPT to use the demos?

No. The demos on this page work in your browser without an account. You’ll need a ChatGPT session with Cutaway and suitable file and code tools to generate a new one.

Is this the original Anatomy?

Cutaway adapts parts of Ryan’s Anatomy toolkit for ChatGPT and adds its own demos and file delivery instructions. The credits above link to Ryan’s original project.

Can I use these in a lesson or presentation?

Yes. You can share the HTML files, use the SVG drawings, and modify the source under the MIT license. Keep the applicable copyright and license notices when you redistribute them.

Does this site send anything to a model?

No. The demos run locally in your browser, without analytics or external fonts and scripts. To generate a new cutaway, use the plugin in ChatGPT.
